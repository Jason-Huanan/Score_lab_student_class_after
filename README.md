学生成绩管理系统 (Student Score Manager)

这是一个用 C++ 编写的控制台学生成绩管理程序，主要用于综合练习和展示 C++ 基础语法（指针、数组指针、函数指针、枚举等）。

✨ 核心功能
- 动态录入学生数量及三门科目成绩
- 输入校验（确保成绩在 0-100 之间）
- 查看所有学生成绩
- 修改指定学生、指定科目的成绩
- 使用**函数指针**动态选择统计方式（求和、平均分、最高分）
- 统计各科目的班级平均分

🛠️ 编译与运行
使用 Visual Studio 打开 `.slnx` 文件，按 `Ctrl + F5` 即可编译运行。

🧠 技术点
- 全局常量与内部/外部链接的冲突处理
- 二维动态数组的指针传递 (`int (*scores)[SUBJECT_COUNT]`)
- `typedef` 定义函数指针类型并在 `switch` 中动态调用
- 多文件模块化架构（`Constants.h` 提供常量，`Statistics` 负责计算，`StudentManager` 负责业务，`main` 负责菜单）
